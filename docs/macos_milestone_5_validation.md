## Scope

This closure records bounded macOS Apple Silicon / arm64 build-tree evidence
for file-source lifecycle, representative FilterChain and algorithm behavior,
and one RAW-to-HDF5 export round trip. It is not a release, packaging, or
cross-platform parity claim.

Closure baseline: `main` at `1bdd8d8e5ae1ae1454d08e028bbd40e33e1dae2e`.

The evidence uses the repository-local OpenEB / Metavision SDK 5.2 CenturyArks
profile and retained validation records. The closure phase did not rerun
configure, build, CTest, GUI, file-info, export, camera, algorithm, or Linux
validation.

Historical validation records retain their validation-time `Milestone 5 remains
Planned` wording. This summary records the later maintainer closure decision
without rewriting those historical evidence boundaries.

- **Representative processing:** one ROI FilterChain configuration remained

  `ExporterController.Hdf5ExportPreservesGeometry` regression passed 1/1 and

## Defects found and fixed

- Empty RAW file-open failures crossed an uncaught-exception boundary and
  aborted the process. The file-open boundary now reports the exercised
  failures in a controlled dialog and permits recovery to a valid file.
- Same-file reopen/file-switch lifecycle state was reset incompletely. The
  playback open path now resets source-specific state before committing a
  successful replacement source.
- Generic HDF5/H5/DAT offline sources exposed `DeviceUnavailable` when
  hardware-oriented facility lookup assumed a HAL Device. The shared
  file-source path now degrades unavailable generic-offline facilities without
  masking later facility exceptions.
- EBplus-generated HDF5 wrote events without canonical source metadata and
  could reopen through a null-geometry crash. The exporter calls
  `add_metadata_map_from_camera(cam)` before event writes.
- Paused timeline actions other than slider dragging could update position
  without presenting a new frame. Playback controls now route
  `QSlider::valueChanged` through seek while blocking initialization feedback.

This validates bounded source lifecycle and geometry reconstruction across two
geometries; it does not establish compatibility with a second real sensor
recording.

## Observed limitations

- The Time Surface session could show several transient white frames after a
  seek before dynamic output recovered. Reset latency and frame correctness
  were not measured.
- The RAW core playback record observed a partially clipped progress-indicator
  circular handle. It did not block the tested lifecycle functions.
- One arbitrary externally created HDF5 with missing geometry metadata may
  still expose an OpenEB generic-reader robustness issue. The HDF5 fix repairs
  EBplus-generated output, not malformed external inputs.
- Evidence is qualitative where the underlying validation did not measure
  numerical event, pixel, timing, algorithm, or image correctness.
